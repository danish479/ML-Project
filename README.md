# Student Score Prediction Using Machine Learning

## About the Project
This project uses Machine Learning to predict students' final scores based on study-related factors such as study hours, attendance, and homework performance.

It is a beginner-level Machine Learning project developed to practice data analysis, model training, and performance evaluation using Python.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Jupyter Notebook
- Linear Regression

## Project Workflow
1. Prepare and explore the dataset.
2. Split the data into training and testing sets.
3. Train a Linear Regression model.
4. Predict students' final scores.
5. Evaluate model performance using MAE, MSE, and R².
6. Visualize the results.

## Project Files
- `student_score_prediction.html` — HTML version of the notebook for viewing the code and results in a browser.

## Purpose
The purpose of this project is to develop practical skills in Python programming and introductory Machine Learning.

## Future Improvements
- Use a larger and more realistic dataset.
- Compare Linear Regression with other Machine Learning algorithms.
- Improve model performance through feature engineering and evaluation.
